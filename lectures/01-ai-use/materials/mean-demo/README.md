# 강사 시연 · 실행 성공과 계산 정확성

챕터 1 단원 06의 짧은 시연 자료다. 학생의 블로그 실습 입력과 구분한다. 기존 교재의 의도적 결함과 검사 코드를 별도 파일로 보존했다.

1. 이 폴더의 두 Python 파일을 별도 시연 폴더로 복사한다. Python 3 실행기를 확인한다.
2. `python mean_voltage.py` 실행: 예상 출력 `20.0`. 단위 정의에 따른 정답은 `2.0`이다.
3. `python check_mean.py` 실행: 첫 검사에서 `AssertionError`가 나야 한다.
4. 복사한 mean_voltage.py의 `value / 100` 한 곳만 `value / 1000`으로 바꾼다.
5. 같은 두 명령을 다시 실행한다. 예상 출력은 `2.0`, `4 checks passed`다.

검사는 기본 입력·한 값·0 포함 입력·빈 목록 처리 네 사례다. CSV 읽기·그래프·모든 입력을 검증한 결과는 아니다. `assert`를 쓰는 학습용 검사이므로 `-O`로 실행하지 않는다. 실제 실행 여부는 강사의 관찰로 기록한다.
