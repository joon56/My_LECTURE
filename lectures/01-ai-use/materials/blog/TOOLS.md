기존 공식 문서 확인일: 2026-10-04. **학생 환경 실행 미검증.** 이번 교안은 Codex 또는 Claude Code 중 실제 하위 에이전트를 사용할 수 있는 환경 하나로 진행한다.

2. 공통 프롬프트로 실제 하위 에이전트 3개가 생성되고 각각 결과를 반환하는지 리허설한다.
