## 강의 목표와 준비

모델·앱·맥락·도구의 역할과 작성·저장·실행·검증의 차이를 이해한다. CSV는 쉼표로 열을 나눈 텍스트 표다. 아래 합성 자료의 첫 행은 열 이름, 이후 세 행은 시간·전압 값이다. 강사는 파일 읽기와 실행 증거를 시연한다. 실행 환경이 없으면 사례 설명으로 표시한다.

## 개념 설명: 화면에 보이는 답 뒤에 무엇이 있는가

**모델**은 제공된 정보를 바탕으로 응답이나 도구 호출을 생성하는 계산 시스템이다. **앱 또는 호스트**는 대화 화면, 파일 연결, 명령 실행, 권한 등을 제공한다. Codex와 Claude Code라는 제품 이름만으로 현재 세션에서 어떤 파일을 읽을 수 있는지까지 알 수는 없다. 실제로 연결된 작업 폴더와 도구 결과를 확인해야 한다.

**맥락(context)**은 이번 응답을 만들 때 모델에 제공된 정보다. 사용자 메시지, 지침, 앞선 대화, 읽은 문서, 도구 결과가 포함될 수 있다. 디스크에 파일이 존재한다는 사실과 그 내용이 이번 맥락에 들어왔다는 사실은 다르다. 사람이 책 제목만 들었다고 그 책의 모든 실험값을 읽은 것은 아닌 것과 같다.

텍스트는 **토큰(token)**이라는 처리 단위로 나뉜다. 한 단어가 여러 토큰일 수도 있으므로 글자 수를 토큰 수로 그대로 바꾸지 않는다. 생성형 언어모델의 기본 설명은 “앞서 주어진 정보를 조건으로 다음 출력을 생성한다”다. 자기어텐션은 토큰 사이의 관계를 계산하는 장치다. 단, 학습 중 여러 위치를 병렬 계산하는 이야기와 응답을 순서대로 생성하는 이야기는 구분한다. 이 원리만으로 특정 요청문이 반드시 성공한다거나 모델의 모든 오류 원인을 설명할 수는 없다.

**학습된 능력**, **현재 읽은 문서**, **제품이 저장한 메모리**도 구분한다. 데이터 설명서를 읽어 단위를 알아낸 것은 현재 작업에 정보를 제공한 것이다. 모델 가중치를 새로 학습시킨 일이 아니다. 메모리가 있는 제품도 저장·검색·주입 규칙이 별도로 있으므로 “지난번에 말했으니 지금도 안다”를 확인 없이 전제로 삼지 않는다.

**도구(tool)**는 파일 읽기, 코드 실행, 검색처럼 환경과 상호작용하는 기능이다. 모델이 `print(2)`라는 코드를 답변에 썼다고 Python이 실행된 것은 아니다. 실행 요청이 실제 도구로 전달되고 그 도구가 결과를 반환해야 실행 증거가 생긴다. **에이전트**는 목표에 따라 이런 행동을 선택하고 관찰 결과를 다음 행동에 반영하는 시스템으로 이해한다.

```text
목표·자료·지침 → 모델이 행동 선택 → 허용된 도구 실행
                         ↑                ↓
                    다음 판단 ← 도구 결과
                         ↓
                  완료 기준과 비교·보고
```

## 강사 진행 대본

### 장면 1 — 같은 “완료”에 네 가지 의미가 있다

**화면:** `분석 코드를 작성했습니다. 평균은 2 V입니다.`라는 가상 응답만 표시한다.

> “지금 확인된 일은 무엇일까요? 평균이 맞는지와 프로그램이 실행됐는지는 다른 질문입니다. 답변에 코드가 있으면 코드 생성은 확인할 수 있습니다. 실제 파일에 저장했는지는 파일을, 실행했는지는 도구 결과를 봐야 합니다.”

**판서:** `작성 → 저장 → 실행 → 검증`. 각 화살표 아래 “추가 증거 필요”를 적는다.

**예상 질문:** “값이 맞으면 실행한 것으로 봐도 되나요?”

**답변:** “손계산이나 추측으로도 맞을 수 있습니다. 이번 입력에서 답이 맞았다는 증거일 뿐, 제출할 프로그램이 동작했다는 증거는 아닙니다.”

### 장면 2 — 모델이 아는 것의 출처를 나눈다

**화면:** 원본 PDF 5쪽 토큰 설명, 8~10쪽 생성·학습 항목. 수식은 선택 심화로 둔다.

> “AI는 우리 연구실의 CSV 열 이름을 태어날 때부터 알지 않습니다. 일반적인 CSV 처리법은 학습했을 수 있지만 이 파일의 단위는 실제 자료로 확인해야 합니다. ‘전압은 보통 V니까 V겠지’는 가정입니다.”

**판서:** `학습된 일반 지식 / 이번에 읽은 자료 / 아직 없는 정보`.

**예상 질문:** “파일 이름에 voltage가 있으면 충분하지 않나요?”

**답변:** “전압이라는 대상만 알 수 있습니다. mV인지 V인지, 결측값이 무엇인지까지는 알 수 없습니다.”

### 장면 3 — 응답과 도구 결과를 나란히 읽는다

**강사 행동:** 아래 CSV를 실제 첨부하거나 작업 폴더에서 읽게 한다. 도구 결과에 열 이름과 세 행이 나타나는지 학생과 확인한다. 실행 환경이 있으면 Python 계산도 별도로 실행한다.

> “여기 파일 읽기 결과가 있으므로 모델이 어떤 데이터를 받았는지 확인할 수 있습니다. 이제 실행 결과도 보겠습니다. 종료가 성공했다는 사실과 계산이 요구사항에 맞다는 사실은 다시 구분해야 합니다.”

**예상 질문:** “에이전트가 성공했다고 표시하면 끝 아닌가요?”

**답변:** “프로세스 종료 성공은 하나의 증거입니다. 잘못된 단위로 계산한 프로그램도 오류 없이 끝날 수 있습니다.”

### 장면 4 — 근거가 있는 작업 보고로 바꾼다

> “‘AI가 다 했다’를 다음처럼 바꿉니다. ‘세 행을 읽었다. mV를 1,000으로 나누었다. 결과는 1·2·3 V다. 손계산 평균 2 V와 비교했다.’ 이렇게 써야 다음 사람이 빠진 검사를 찾을 수 있습니다.”

**강사 시연:** 강사가 증거표를 보여준다. 실행 증거가 없는 항목은 `실행 미확인`으로 표시하고 이유를 설명한다.

## 완성 예제: 답의 근거를 추적하기

아래 데이터는 수업용 합성 자료다. 센서 실험 결과나 특정 장비 성능을 뜻하지 않는다.

```csv
time_ms,voltage_mv
0,1000
1000,2000
2000,3000
```

**정확한 요청 입력:**

```text
첨부한 CSV의 실제 내용을 먼저 확인해줘.
time_ms는 ms, voltage_mv는 mV다.
시간을 s, 전압을 V로 변환하고 전압의 산술평균을 구해줘.
읽은 행 수, 변환식, 결과를 적어줘.
실행 도구를 쓰지 않았다면 계산 설명과 실행 결과를 구분해줘.
```

**기대 출력:** 행 수 3, 시간 `[0, 1, 2] s`, 전압 `[1, 2, 3] V`, 평균 `2 V`. 이는 정답 기준이며 특정 모델의 실제 출력 기록이 아니다.

**확인 방법:** `1000 ms = 1 s`, `1000 mV = 1 V`에서 나누는 수가 각각 1,000임을 확인한다. `(1+2+3)/3=2`를 손으로 계산한다. 프로그램을 실행했다면 입력 파일 경로, 실행 명령, 출력, 종료 상태도 남긴다. 파일 이름만 전달한 조건에서는 실제 내용을 확인하지 못했다고 밝히거나 읽기 도구를 써야 한다. 파일 내용 없이 정확한 결과를 단정하면 근거 부족이다.

## 오개념과 강의 요점

- **“AI는 결국 자동완성이라 계산을 못 하나요?”** 생성 방식의 설명만으로 능력 전체를 단정할 수 없다. 실제 과제에서 확인하고, 정확한 반복 계산은 검증한 프로그램으로 수행한다.
- **“같은 모델이면 같은 일을 할 수 있나요?”** 제공 자료와 도구, 권한, 실행 환경이 다르면 작업 범위가 달라진다.
- **“문서를 읽히면 모델이 영구적으로 배우나요?”** 현재 맥락 제공과 가중치 학습은 구분한다. 다음 세션의 접근 여부도 확인한다.

강의 요점: 작성·저장·실행·검증에는 각기 다른 증거가 필요하다.

## 근거와 적용 범위

- [Attention Is All You Need](https://arxiv.org/abs/1706.03762): 역사적 Transformer 구조 설명. 현재 비공개 제품의 구현 설명으로 확대하지 않는다.
- [Building effective agents](https://www.anthropic.com/engineering/building-effective-agents): 도구와 피드백을 사용하는 에이전트 설명.
- [공식 출처 확인 기록](../../../research/sources.md): 2026-10-03 확인 스냅샷. 본 단원의 카드·평가표는 교육 설계이며 학생 시연 결과는 별도 기록한다.

강의의 측정값·CSV는 개념을 설명하는 시연 예제다. 챕터말 학생 과제는 공통 주제의 블로그 제작이며, CSV 프로그램을 미리 만들 필요가 없다.
