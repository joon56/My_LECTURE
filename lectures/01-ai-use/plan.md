# 챕터 1 설계 · AI와 문제를 정의하고 구현·검증하기

운영 순서: **챕터 1 강의 전체 → 챕터 1 실습 → 챕터 2 강의 전체 → 챕터 2 실습.** 강의 사이에 학생 파일 작성·설정·제출을 끼워 넣지 않는다. 학생 활동은 [챕터 1 실습](practice.md)에 모았다.

## 목표와 대상

공대 후배가 AI의 응답을 작업 명세, 실제 파일·실행, 독립된 검사, 다음 사람에게 넘길 기록으로 연결하게 한다. Codex와 Claude Code를 모두 설명하되 실제 수행은 사용할 수 있는 도구 하나로 시작한다. 시간보다 개념의 깊이와 재현 가능한 절차를 우선한다.

핵심 흐름은 문제 정의→맥락 준비→위임→실행→검증→기록이다. 학생이 결과의 입력·출력·가정·오류 정책과 본인의 판단을 설명하는 것이 목표다. 실제 연구실 과제·학생 운영체제·계정·수준은 별도로 확인한다.

## 강의 구성

## 강의 예시와 실습 자료

공통 예시는 손계산 가능한 합성 전압 CSV다. CSV는 쉼표로 열을 나눈 텍스트 표이며 실제 연구 결과가 아니다. 열은 `time_ms,voltage_mv`, 행은 `0,1000`, `1000,2000`, `2000,3000`이다. s·V로 변환하면 시간 0·1·2, 전압 1·2·3, 평균 2 V다.

강의에서는 원리와 완성 예시를 읽는다. 실습은 강의 저장소 밖의 새 `ai-lab` 폴더, UTF-8·확장자·실행 위치 확인부터 시작한다. [제공 정상 파일](materials/samples.csv)과 오류 CSV의 복사·직접 작성 방법을 실습 문서에 모두 넣었다. 기존 파일·코드·AI 응답이 준비되어 있다고 가정하지 않는다.

CSV 프로그램의 단계는 읽기·검증→변환·요약→단순 SVG 그래프다. 학생은 명세에 따라 AI와 프로그램을 생성하고 실제 실행한다. 추가 패키지·웹 서버·장비 제어·외부 업로드는 기본 범위 밖이다. 오류 입력은 정상 결과를 만들지 않고 이전 정상 결과를 보존한다. 설치되지 않은 확장을 이미 동작한다고 표시하지 않는다.

## 챕터말 실습 설계

| 활동 | 산출물·확인 |
|---|---|
| 준비 | 새 폴더, 정상·오류 CSV, Python·AI 접근 상태 |
| 명세 | SPEC.md, 독립 예상값, 작업 의존 관계 |
| 요청·가설 비교 | A/B/C 요청, N/W/C/G 의견 조건, 원응답과 근거별 판정 |
| 디버깅 | /100 결함 재현, /1000 수정, 네 검사 |
| CSV 구현 | 실제 프로그램, 변환·요약·그래프, 정상·오류 실행 |
| Markdown·지침 | 수정 전후 규칙, 문서 표시·로딩·행동 구분 |
| 맥락·인계 | STATUS와 기록, 파일 대조, 짝 또는 새 세션 재개 |
| 종합 | 실행법·근거·한계와 본인 판단 설명 |
| 선택 확장 | Skill 적용 검사, MCP 문서 조회, Plugin 읽기·도입 판단 |

구체 요청문·명령·예상 결과·파일 경로·이전 활동 대응표는 [실습 문서](practice.md)를 기준으로 한다. 풀이와 채점은 학생 안내 뒤에 둔다. 문서를 쓴 상태, 프로그램 동작 확인, 학생 이해를 구분한다.

## 평가

문제 정의 20, 구현·결과 20, 검증 30, 기록·인계 15, 직접 설명 15점. 권장 통과는 75점 이상과 필수 항목 충족이다. 원본 보존, 단위·평균 정확성, 오류 정책, 실제 실행 여부의 정직한 기록은 점수와 별도로 확인한다. 기능 설치 수를 평가하지 않는다.

비교는 같은 입력·도구·지침에서 요청 조건을 바꾸고 원출력과 실제 관찰을 남긴다. 짧은 수업 결과로 성능 향상률·동조 발생률을 일반화하지 않는다. 사용자의 취향은 존중하고 계산·원인 가설은 자료로 검증한다. 무조건 반대하는 답을 정답으로 삼지 않는다.

## PDF·제품 근거와 강사 준비

각 원고의 PDF 연결 상자는 물리적 페이지, 활용·교정·새 내용을 유지한다. 29쪽의 형식 지정은 few-shot과 구별하고, 영→불 BLEU 41.0 표기는 원논문 41.8과 대조한다. MECE는 실행 독립성을 보장하지 않으며 CoT 권고·연구 평가는 모델과 과제의 적용 범위를 밝힌다.

강사는 실제 파일 읽기·실행 화면, 원논문과 보고서 그림, 정상·오류 입력, Python 환경을 준비한다. 도구 연결이 없는 수업에서는 설명·문서 상태까지만 기록한다. 제품 지침·Skill·MCP·Plugin의 경로와 명령은 단원·실습의 공식 문서와 확인 날짜를 기준으로 확인하고 학생 환경에서 별도 검증한다.

현재 CSV 분석 프로그램과 학생별 설정·계정·실제 수행은 실습에서 생성·확인할 대상이다. 교재 예제 검증을 모든 학생 환경의 성공으로 확대하지 않는다.
